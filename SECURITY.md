# Security policy

The current `main` branch is the only supported version of this demonstration
project. It is not a production booking service.

Please report a suspected vulnerability privately through the repository's
[GitHub security advisories](https://github.com/Eloe321/slot-allocation-model/security/advisories/new).
Include reproduction steps, the affected commit, and the impact. Please do not
post exploit details in a public issue before a fix is available.
